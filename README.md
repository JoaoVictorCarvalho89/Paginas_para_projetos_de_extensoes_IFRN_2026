# Páginas para Projetos de Extensão - IFRN Canguaretama (2026)

Este repositório é destinado ao desenvolvimento e à publicação de **três páginas HTML** institucionais focadas na divulgação de projetos de extensão desenvolvidos no **Instituto Federal do Rio Grande do Norte (IFRN) - Campus Canguaretama**.

---

## 📌 Sobre o Projeto

O objetivo principal deste projeto é dar visibilidade às ações de extensão do IFRN Canguaretama, apresentando à comunidade interna e externa os impactos, objetivos e resultados alcançados pelas iniciativas.
